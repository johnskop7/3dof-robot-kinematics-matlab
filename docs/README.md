# Documentation

This directory contains the original materials associated with the Robotics I semester project:

- `course-handout.pdf` - original NTUA project specification.
- `theoretical-analysis.pdf` - Ioannis Litsos's handwritten analytical derivation, scanned to PDF. The student registry number and email have been redacted for public sharing.
- `simulation-report.pdf` - report for the MATLAB kinematic simulation. The student registry number and email have been redacted for public sharing.

The theoretical analysis and simulation report are complementary parts of the same project.
